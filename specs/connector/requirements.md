# CONN-STIRLINGPDF-AGENT — Requirements

Governing spec: [spec.md](spec.md).

| ID | Requirement | Acceptance |
|---|---|---|
| `CONN-STIRLINGPDF-AGENT-R001` | **Read-only status operation.** The connector must expose `stirlingpdf_get_status`. The tool must call `GET /api/v1/info/status` in `stirlingpdf_agent/api/api_client_watermark.py`. The tool must carry the read-only annotation. Caller chain: an MCP client calls `stirlingpdf_get_status` in `stirlingpdf_agent/mcp_server.py`, which calls `get_status` (`stirlingpdf_agent/api/api_client_watermark.py:37`). Shape: the read-only tool `stirlingpdf_get_status` and `get_status` in `stirlingpdf_agent/api/api_client_watermark.py` for `GET /api/v1/info/status`; the tool carries the read-only annotation. Proving test: `tests/test_read_only_status.py::test_status_tool_is_listed_read_only`. | `tests/test_read_only_status.py` must show: the tool is listed with the read-only annotation, calls the status route with the API key header, maps a 401 response to an authentication error, and succeeds with no API key configured. |
| `CONN-STIRLINGPDF-AGENT-R002` | **Fleet name.** `pyproject.toml` declares `stirlingpdf-mcp` as the single `scion_sdk.connector` entry point. The content pack, the manifest `connector`, the fingerprints and the ingest binding all carry `stirlingpdf-mcp`. Caller chain: `stirlingpdf-mcp` in `pyproject.toml` runs `scion_sdk.cli:serve`, which builds the server from the `scion_sdk.connector` entry point `stirlingpdf_agent:connector` (`stirlingpdf_agent/__init__.py:9`); `connector_name("stirlingpdf_agent")` in the SDK resolves the same entry point name for the content pack, the manifest and the ingest binding. Shape: `pyproject.toml` entry point `stirlingpdf-mcp`, the `connector_name` helper of the SDK and the `ConnectorContent`/`IngestBinding` calls under `stirlingpdf_agent/`; reuses the SDK name resolution and adds no second constant. Proving test: `tests/test_fleet_name.py::test_connector_name_is_the_fleet_name`. | Every connector name in the package is `stirlingpdf-mcp`. |
