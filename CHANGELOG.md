# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.4.8] - 2026-10-30

### Changed
- Require `scion-sdk>=0.6.4,<0.7.0`; `uv.lock` relocked.

## [2.4.6] - 2026-10-26

### Added
- Standard spec-delivery dashboard publication and the Stirling PDF connector
  development skill with the rapid-delivery contract.

## [2.4.5] - 2026-10-24

### Changed
- Central connector migration: requires `agent-connector-sdk>=0.5.4`; server bootstrap, version, containers, ontology artifacts, security scaffold and pre-commit config are provided centrally.

## [Unreleased]

### Added
- Standardized concept tags and definitions mapped to `AGENTS.md` for full project traceability.
- Expanded connection and configuration settings placeholders inside `.env` and `.env.example`.

## [0.14.0] - 2026-05-22

### Added
- Dynamic Action-Routed PDF MCP tools grouping capability for optimized token footprint.
- Complete test coverage filling suites achieving 100% absolute branch and statement coverage.
- Fully verified standard security integrations including Eunomia authorization policy engines.

### Changed
- Refactored `README.md` introducing detailed Quick Start guides, environment variables documentation, and tools mapping lists.

### Fixed
- Fixed RequestsDependencyWarning handling and import reloading coverage edge cases.
